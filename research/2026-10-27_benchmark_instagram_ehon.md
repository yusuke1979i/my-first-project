## 1. Instagram（③ 副業支援ノウハウ販売）

### 1-1. 2026年に伸びる条件（複数の記事に共通していた内容）
| 優先度 | 指標 | 意味 | 投稿で狙うこと |
|---|---|---|---|
| ★★★ | **送信（DMシェア）** | 2026年は保存より重視するという運用会社の見方あり | 「副業したい友達に送って」と思わせる内容 |
| ★★★ | **視聴維持率・最後まで見られたか** | 最後まで見られる動画ほど拡散されやすい | 冒頭3秒のフック、15〜30秒の短い構成 |
| ★★ | **保存** | 「あとで見返したい」という価値の評価 | 手順・チェックリスト・〇選 |
| ★ | いいね | 優先度は低め | — |

- 2026年5月の更新で**転載・まとめ系アカウントのリーチが落ちた**とする記事がある（Metaの公式発表では未確認）→ **自分の実体験（Etsy・Noteの実績）を出す発信が有利**
- 再生数は「閲覧数（Views）」に統合された

### 1-2. 売れるアカウントの共通点
1. **1アカウント1テーマ**（例：「Etsy×Noteでデジタル商品を売る」に絞る）
2. **フォロワー数と売上は比例しない**：フォロワー10万人でも、副業コンサルの集客が月2人だった事例あり → **導線の設計が売上を決める**
3. **Instagram単体ではなく LINE公式と組み合わせる**：教育・販売はLINEで行う
4. **顔出しなしでも成立する**（主婦・会社員の事例が多い）
5. **入口は低価格のPDF（980円前後）→ PR案件・高単価商品へ** という段階構成

### 1-3. 導線の型：コメント→DM自動送信
```
リール「"手順書"とコメントで無料配布」
  → コメントした人に自動DMを送る（Meta公式APIの認定ツールを使う）
  → DMでLINE登録URLを案内
  → LINEで無料PDF → 体験談 → 無料相談 → 伴走サポートの案内
```
- 必要なもの：**ビジネスアカウントかクリエイターアカウント**、DM自動化ツール
- コメントが増えるとエンゲージメント率が上がるので、リーチも伸びやすい
- 失敗例：保存されない／プロフィールに来ない／リンクが踏まれない → 「続きはプロフィール」の誘導と、リンク先で何がもらえるかを明示する

### 1-4. Rapidomで使うリールの型（仮説・まず10本で検証）
| 型 | 冒頭3秒の例 | 狙う指標 |
|---|---|---|
| ① 実績公開 | 「Etsyでデジタル商品が初めて売れた日の画面です」 | 視聴維持・プロフィール訪問 |
| ② 〇ステップ | 「Noteで手順書を売るまでの5ステップ」 | 保存 |
| ③ 失敗談 | 「Etsyで最初の1ヶ月 売れなかった理由3つ」 | 視聴維持・送信 |
| ④ ツール紹介 | 「デジタル商品づくりに使っている無料AIツール3つ」 | 保存・送信 |
| ⑤ コメント配布 | 「"手順書"とコメントで、私の出品チェックリストを配ります」 | コメント→LINE |
| ⑥ 比較 | 「Etsy と Note、初心者が先にやるべきはどっち？」 | 送信・コメント |

### 1-5. 重要な発見：Etsyは日本からの新規出店が可能（ただし条件あり）
- 2021年4月〜2023年11月は日本からの新規出店が止まっていた。現在は **Payoneer口座を経由した Etsy Payments 登録で出店できる**（2026年9月時点の体験記で確認）
- 手順の例：Payoneer → Etsy Payments → 本人確認 → 海外発送 → 関税・GPSR → ショップポリシー
- **手順書では、この開設手順を2026年の最新版で丁寧に書くことが大きな価値になる**（初心者が一番つまずく所）。ただし、ルールは変わる可能性があるため、出版前にEtsy公式ヘルプで再確認する。

### 2-2. 親のレビューから見えた不満点（＝差別化のヒント）
| 不満 | Rapidom絵本での対策 |
|---|---|
| 絵本なのに**文字が多く、説明が難しい** | 1見開き1メッセージ、文字は少なく。説明は巻末の「親向けページ」に回す |
| 子どもが働いてお金を稼ぐ設定に**現実味がない** | 「おこづかいの使い方」「欲しいものを選ぶ・待つ」など、5〜7歳が実際にできる行動に絞る |
| 主人公の行動に親が共感できない | 失敗→気づき→小さな成功、という素直な成長の流れにする |
| 銀行・投資・税金を一冊で全部扱っていて散漫 | **テーマは1冊に1つ**（例：「待つと増える＝貯める」）。シリーズ化を前提にする |

### 2-3. 売れている本の共通点 → Rapidom絵本の勝ち筋（仮説）
1. **親が買う理由がタイトルにある**（「6歳から」「60分で読める」「はじめての」）→ 対象年齢と効果をタイトルで明示する
2. **監修・実績による信頼**（専門家監修・全米ベストセラー）→ 著者の実績、可能ならFPの監修を表に出す
3. **遊べる仕掛け**（クイズ・お買い物ごっこ）→ **巻末に「おうちで使える おこづかいワークシート」**（印刷できるPDFのダウンロード付き）
4. **投資テーマはまだ少ない** → 第2弾の候補
5. 未就学児向け（2〜5歳）と小学生向けで本が分かれている → **ねらう枠は「5〜7歳＋親」**（文字は少なく、親向け解説を付ける）

**タイトル案（たたき台）**
- 『5さいから はじめる おかねの えほん ― まって、えらんで、ためてみよう』
- 『〇〇くんの おこづかい ― 親子で読む はじめての金融教育』

### 2-4. KDPで絵本を出すときの注意点
- **AI生成のテキスト・画像・翻訳は申告が必要**（2023年9月から）。申告はKDPのコンテンツ設定画面で行い、表紙と中のイラストも対象になる可能性が高い
- AIでアイデアを出しただけ、または自分で書いた原稿の校正にAIを使っただけなら「AI支援」扱いで、申告は不要
- 画像中心の本（絵本・ぬり絵）は**審査が厳しく、長引いているという報告がある**（第三者のブログで、公式発表ではない）→ **11/1の入稿は余裕を見て早めに**。キャラクターが既存作品に似ないよう注意する
- 子ども向けの本は KDP Kids／Kindle Kids' Book Creator で作れる。紙の需要が大きいため**ペーパーバックも同時に出す**

## 3. 調査から導いた結論（計画への反映）
1. **③ 手順書の主力は「2026年版：日本からEtsyを始める完全手順（Payoneer〜初出品）」＋「Noteで手順書を売る方法」** の2本立てにする
2. Instagramは **自分の実績を出すリール ×「コメントで配布」→ LINE** の型に絞る。1日1本、まず10本で検証する
3. 絵本は **「5〜7歳＋親」、1冊1テーマ（待つ・選ぶ・貯める）、巻末に親向け解説とワークシート**。シリーズ化を前提にする
4. KDPの審査が延びる可能性があるため、**入稿日を11/1（日）から10/31（土）へ前倒しすることを推奨**
